# Memory

MishMash Memory keeps durable, editable facts, preferences, project context, references, and verified rules. Saved entries remain available across conversations and can be reviewed or changed under **Settings → Memory**.

## Natural-language capture

Use an explicit command at the start of a chat message and include the note content in that same message:

- `Save this to durable notes: Use the Vimeo API for drag-and-drop video editing.`
- `Log this in the MishMash log: Add inline video trimming.`
- `Remember this: Prefer non-destructive media edits.`
- `Log a bug: The canvas drops the selected layer after undo.`
- `Log an idea: Add reusable timeline presets.`
- `Log a feature: Support Vimeo imports.`

Common polite phrasing, speech-to-text punctuation around `log`, and the common `Mishmag` or `Mishmask` transcription of `MishMash` are accepted.

Explicit commands work while **Learn from chats** is off; ordinary chat is not passively mined. Bugs and remembered preferences are filed under **Feedback**. Ideas, features, and general durable notes are filed under **Project**. Repeating the same command reuses the existing entry instead of creating another copy.

An explicit command without note content does not create an entry. Put the content after the command rather than sending only `log this` or `remember that` as a separate message.
