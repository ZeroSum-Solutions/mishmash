Trade-offs · An honest accounting

Pure-HTML decks: what's good, what hurts

✓ Upside

  • Zero build: one file just runs
  • Diffable: git-friendly, easy to review
  • Programmable: motion is fully customizable
  • Distributable: URL / PDF / PNG, all work

✗ Pain points

  • Collaboration isn't as real-time as Keynote
  • A bit of a learning curve for non-developers
  • Complex motion still needs hand-written JS
  • Some fonts are missing offline
