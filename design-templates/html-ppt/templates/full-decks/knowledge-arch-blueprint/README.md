# knowledge-arch-blueprint

Cream paper (`#F0EAE0`) background + a single rust-red (`#B5392A`) accent + hard black-bordered cards + dashed feedback-loop arrows. Inspired by `20260405-architecture-diagram-v2.html` — a genuine "technical white-paper architecture diagram" that reads like a building blueprint.

**Visual traits:** a warm cream paper background, a faint 48px grid for the blueprint feel, crisp 2px black-bordered cards, pipeline step-boxes lined up in a row with one hero box raised, a red insight callout in the top-right, upper/lowercase kicker at 2.5-4px letter-spacing, an SVG dashed feedback loop + arrows, big Playfair serif numerals for data, zero gradients and extremely restrained shadows.

**Use when:** explaining system architecture, data flow, or a process breakdown; you want the content to read like a serious technical white paper rather than a marketing post; you need gravitas, a printed feel, something you can screenshot straight into a README.
