# dir-key-nav-minimal

8 slides, each its own solid/gradient mono-background (indigo / cream / crimson / emerald / slate / violet / white / charcoal). Directly inspired by `20260405-demo-slides-arrow-key-edition.html` — eight `t-*` theme classes, one background per slide, arrow-key navigation, a minimalist editorial tone.

**Visual traits:** a distinct background color + single accent per slide, a giant 160px headline with no supporting image, a 4px short-and-stubby accent-line divider, an arrow-prefixed mono list, a `← →` keyboard hint bottom-left + a page label bottom-right, full-screen breathing negative space, JetBrains Mono for numbers / code / the keyboard hint, each background has its own `.dk-accent` color.

**Use when:** you have something to say and not much to show, and want typographic rhythm to carry the audience's attention; a keynote-style minimalist talk; one idea per slide; public talks / keynotes / presentations.
