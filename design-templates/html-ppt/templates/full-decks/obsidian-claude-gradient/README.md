# obsidian-claude-gradient

GitHub-dark (`#0d1117`) + a purple ambient radial + a 60px masked grid + purple→blue→green gradient text. Inspired by the `--accent #7c3aed`, the `.cbg` dual-radial cover, the `.cgrid` 60px masked grid, and the `.g` three-stop gradient from `20260406-obsidian-claude/slides.html`.

**Visual traits:** a dark gray-blue background + purple-blue radial glow + a dark grid mask, center-aligned title/body, rounded purple pill tags, `#a855f7→#60a5fa→#34d399` linear gradient text, GitHub-ish code colors (`#010409` background + purple/blue/orange/green tokens), a purple left-border highlight block, a clean step list.

**Use when:** walking through a developer-friendly workflow, an MCP / Agent / dev-tool tutorial; you want a tone close to the GitHub Blog / Linear Changelog; content is mostly config files + steps.

**Source inspiration:** `20260406-obsidian-claude/slides.html`.
