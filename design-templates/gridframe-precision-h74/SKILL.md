# Meridyne — Precision Grid Studio Growth Agency Landing Page

> Landing page vendored from the MIT-licensed `pulkitxm/claude-directory` gallery.

A full, multi-section, responsive landing page for a fictional growth-systems studio named Meridyne — "we engineer marketing systems, not campaigns." The Precision Grid Studio design language is calm and architecturally ruled — like a Swiss engineering dossier on warm paper — with every module inside a hairline cell, plus-crosshair registration marks at key frame corners, and forest green used sparingly against butter-cream accents.

## Workflow

1. **Clone `example.html`** into the user's workspace as the working file.
2. **Replace placeholder content** with the user's real brand name, headlines,
   body copy, numbers, and imagery. Match existing image dimensions when
   swapping assets.
3. **Preserve the design system.** The palette, type scale, spacing rhythm, and
   motion in the build spec below are the identity — do not substitute fonts,
   recolour the palette, or strip decorative elements.
4. **Extend by duplicating sections**, never by importing a layout from another
   template. If a section is missing, design it from scratch in this template's
   own vocabulary.
5. **Keep motion accessible.** Every animation must stay behind
   `prefers-reduced-motion`, as the build spec requires.

## Build spec

The upstream prompt that produced this design, verbatim.

# MERIDYNE — "PRECISION GRID STUDIO" ENTERPRISE GROWTH-SYSTEMS LANDING PAGE

## NAMED AESTHETIC IDENTITY

BUILD A FULL, MULTI-SECTION, FULLY RESPONSIVE MARKETING LANDING PAGE FOR A FICTIONAL HIGH-TIER GROWTH-SYSTEMS STUDIO NAMED **MERIDYNE** — "WE ENGINEER MARKETING SYSTEMS, NOT CAMPAIGNS." THE NAMED DESIGN LANGUAGE IS **"PRECISION GRID STUDIO"**: A CALM, EXPENSIVE, ARCHITECTURALLY-RULED AESTHETIC THAT FEELS LIKE A SWISS ENGINEERING DOSSIER PRINTED ON WARM PAPER. EVERY MODULE LIVES INSIDE A HAIRLINE-RULED CELL, EVERY MAJOR FRAME IS PUNCTUATED AT ITS CORNERS BY SMALL "PLUS" CROSSHAIR MARKERS (LIKE REGISTRATION MARKS ON A PRINT SHEET), AND COLOR IS USED SPARINGLY AS STRUCTURE. THE MOOD IS CONFIDENT, MEASURED, AND INSTITUTIONAL — THE OPPOSITE OF SOFT ROUNDED SAAS. STRICTLY AVOID GENERIC-AI-SLOP: NO PURPLE GRADIENTS, NO GLASSMORPHISM, NO NEON, NO BLURRED DROP SHADOWS, NO EMOJI.

## COLOR SYSTEM

- DEEP FOREST GREEN (BRAND PRIMARY): `RGB(48, 74, 58)` / `#304A3A` — USED FOR SOLID NAV CTA, THE BIG CLOSING CTA PANEL, STAT NUMBERS, AND BRAND ACCENTS.
- BUTTER CREAM (BRAND ACCENT): `RGB(245, 240, 214)` / `#F5F0D6` — USED FOR THE HERO TESTIMONIAL CARD, THE CAPABILITIES BAND BACKGROUND, AND AS THE INVERTED TEXT COLOR ON GREEN.
- WARM PAPER (PAGE BACKGROUND): `RGB(247, 246, 242)` / `#F7F6F2`.
- INK BLACK (PRIMARY TEXT): `RGB(17, 19, 17)` / `#111311`.
- SLATE (SECONDARY TEXT): `RGB(104, 110, 104)` / `#686E68`.
- HAIRLINE BORDER: `RGB(206, 205, 197)` / `#CECDC5`.
- PLUS-MARK GREY: `RGB(150, 152, 146)` / `#969892`.

## TYPOGRAPHY

- ONE FAMILY THROUGHOUT: **INTER TIGHT** (WEIGHTS 400/500/600/700), SELF-HOSTED / VENDORED LOCALLY. FALL BACK TO INTER, SYSTEM-UI, SANS-SERIF.
- HEADINGS: WEIGHT 500, TIGHT TRACKING (`-0.04EM`), LINE-HEIGHT ~1.05–1.1. HERO H1 RANGES `CLAMP(42PX … 78PX)`.
- NAV / EYEBROW / LABELS: UPPERCASE, BOLD (700), WIDE TRACKING (`0.1EM–0.25EM`), 11–13PX.
- BODY: 18–22PX, RELAXED LEADING, SLATE COLOR.
- BRAND WORDMARK: BOLD, UPPERCASE, SLIGHT ITALIC, WIDE LETTER-SPACING.

## SIGNATURE MOTIFS (USE THROUGHOUT)

- **PLUS CROSSHAIR MARKERS**: A 15×15PX "+" DRAWN WITH TWO 3PX-THICK BARS, PINNED HALF-OUTSIDE THE CORNERS OF KEY FRAMES (NAV BAR, HERO SECTION, CARDS, CTA, FOOTER) — ALWAYS OFFSET BY `-8PX` SO THEY STRADDLE THE BORDER LIKE REGISTRATION CROSSHAIRS. ON THE GREEN CTA THEY TURN CREAM.
- **HAIRLINE CELL GRID**: SECTIONS AND NAV ITEMS ARE DIVIDED BY 1PX HAIRLINE BORDERS; THE WHOLE PAGE READS AS A STACK OF RULED FRAMES.
- **TEXT FLIP-UP HOVER**: NAV LINKS AND MENU-LIST LINKS REVEAL A GREEN FILL THAT SLIDES UP FROM THE BOTTOM WHILE THE LABEL TRANSLATES OUT AND A CREAM DUPLICATE SLIDES IN (OVERFLOW-HIDDEN "FLIP" EFFECT).

## LAYOUT & SECTION BREAKDOWN (TOP TO BOTTOM)

1. **STICKY-FEEL NAV (CELLED BAR)**: A FULL-WIDTH BORDERED BAR INSIDE A MAX-WIDTH WRAPPER, HEIGHT ~64PX, WHITE-ISH FILL. LEFT CELL = ICON + "MERIDYNE" WORDMARK, DIVIDED BY A RIGHT BORDER. CENTER = DESKTOP NAV ITEMS (STRATEGY, CAPABILITIES, IMPACT, FAQ) EACH IN ITS OWN BORDERED CELL WITH THE FLIP-UP HOVER. RIGHT = A "CLIENT PORTAL" TEXT LINK CELL + A SOLID GREEN "START A BRIEF" CTA CELL (CREAM TEXT, FLIP-UP HOVER TO WHITE/GREEN). PLUS MARKERS AT THE BAR'S OUTER CORNERS. A HOVER-DRIVEN **MEGA MENU** DROPS FROM "STRATEGY" AND "CAPABILITIES": A 12-COLUMN PANEL WITH A CREAM-TINTED LEFT SIDEBAR (EYEBROW + IMAGE + DESCRIPTION + "DISCOVER MORE" UNDERLINE LINK) AND TWO RIGHT COLUMNS OF FLIP-UP LINK LISTS, ALL CONTENT SWAPPED PER TRIGGER VIA JS. MOBILE = HAMBURGER OPENING A FULL-SCREEN SLIDE-IN OVERLAY.

2. **HERO** (BORDERED SECTION, PLUS MARKER TOP-RIGHT): TWO-COLUMN GRID — LEFT (FLUID) HAS H1 "ENGINEERED GROWTH FOR ENTERPRISES THAT REFUSE TO GUESS.", A SLATE SUB-PARAGRAPH, AND A PILL-SHAPED GREEN CTA WITH A DIVIDED ARROW CHIP ON ITS RIGHT END THAT NUDGES ON HOVER. RIGHT (FIXED ~500PX) HAS A CREAM TESTIMONIAL CARD WITH HARD CORNERS + PLUS MARKER, CONTAINING A ROW OF FOUR OVERLAPPING CIRCULAR TEAM PORTRAITS, A LARGE GREEN PULL-QUOTE ("EFFICIENCY IS THE PRODUCT. WE HELP AMBITIOUS FIRMS RECLAIM 40% OF THEIR STRATEGIC BANDWIDTH."), AND A "SEE THE METHODOLOGY ↗" FOOTER LINK.

3. **LOGO MARQUEE STRIP** (BORDERED): SMALL UPPERCASE EYEBROW "TRUSTED BY CATEGORY LEADERS", THEN AN INFINITE LEFT-SCROLLING MARQUEE OF FICTIONAL WORDMARKS (NEXUS·CO, ORBITAL, QUANTUM, VANTAGE, EQUINOX, ZENITH, MERIDIAN, HALCYON) AT LOW OPACITY THAT BRIGHTEN ON HOVER; SEAMLESS DUPLICATED TRACK.

4. **STRATEGY SECTION (`#strategy`)**: TWO-COLUMN. LEFT = EYEBROW WITH A SHORT RULE ("— OUR APPROACH"), H2 "ARCHITECTURAL PRECISION, APPLIED TO GROWTH.", PARAGRAPH, THEN A HAIRLINE-RULED 2-UP OF NUMBERED STEPS (01. STRUCTURAL AUDIT / 02. GROWTH BLUEPRINT) WITH A PLUS MARKER AT THE RULE INTERSECTION. RIGHT = A SQUARE FRAMED IMAGE CARD (PADDED, BORDERED, HARD CORNERS) WITH PLUS MARKERS AT TWO OPPOSITE CORNERS.

5. **CAPABILITIES BAND (`#capabilities`, CREAM BACKGROUND)**: HEADER ROW WITH H2 "CORE CAPABILITIES" + INTRO + A "VIEW FULL SERVICE LIST →" UNDERLINE LINK. THEN A 4-UP CARD GRID JOINED BY 1PX GAPS (CELL GRID), EACH CARD WITH A LINE-ICON, TITLE, AND BLURB — MARKET INTELLIGENCE, BRAND ENGINEERING, PERFORMANCE MEDIA, REVENUE OPS — EACH HOVER-FILLING TO PAPER-WHITE WITH A PLUS MARKER FADING IN.

6. **IMPACT / STATS SECTION (`#impact`, BORDERED)**: HEADER ("MEASURED OUTCOMES." + SUPPORTING LINE), THEN A 3-UP OF BIG GREEN STAT NUMBERS THAT **COUNT UP** WHEN SCROLLED INTO VIEW (`+40%` OPERATIONAL BANDWIDTH RECOVERED, `3.5×` AVERAGE MARKETING ROI, `12+` GLOBAL MARKETS ENTERED), EACH OVER A HAIRLINE RULE WITH A PLUS MARKER AT THE RULE'S LEFT END AND A LABEL + DESCRIPTION BELOW.

7. **FAQ SECTION (`#faq`, BORDERED)**: LEFT STICKY HEADER COLUMN (EYEBROW "— INQUIRIES", H2 "COMMON QUESTIONS.", PARAGRAPH, "STILL CURIOUS? CONTACT US →" UNDERLINE LINK). RIGHT = A SINGLE-OPEN ACCORDION OF 4 ITEMS WITH HAIRLINE DIVIDERS AND A "+"/"–" ICON THAT ROTATES; SMOOTH MAX-HEIGHT EXPAND.

8. **CLOSING CTA PANEL (`#contact`)**: A LARGE SOLID FOREST-GREEN PANEL (HARD CORNERS) WITH A FAINT INSET CREAM BORDER MOTIF, CENTERED CREAM HEADLINE "READY TO BUILD A HIGH-EFFICIENCY GROWTH ENGINE?", SUB-COPY, AND TWO BUTTONS (SOLID CREAM "START A BRIEF" + OUTLINE CREAM "VIEW METHODOLOGY"). PLUS MARKERS (CREAM) AT ALL FOUR INNER CORNERS.

9. **FOOTER (BORDERED-TOP)**: 4-COLUMN — BRAND + MISSION LINE, NAVIGATION LINKS, CONTACT BLOCK (HQ, EMAIL, PHONE), AND A NEWSLETTER INPUT WITH A SMALL GREEN SUBMIT CHIP. BOTTOM BAR = COPYRIGHT + PRIVACY/TERMS. PLUS MARKERS AT THE FOOTER'S BOTTOM CORNERS.

## MOTION / INTERACTION SPEC

- **SCROLL REVEAL**: ELEMENTS TAGGED FOR ANIMATION START HIDDEN (OPACITY 0, TRANSLATED 30PX UP, OR ±100PX FROM LEFT/RIGHT FOR HERO COLUMNS) AND EASE INTO PLACE VIA INTERSECTIONOBSERVER WITH A `CUBIC-BEZIER(0.16,1,0.3,1)` ~1.2S TRANSITION; STAGGER THE TWO HERO COLUMNS (300MS / 600MS DELAY).
- **STAT COUNT-UP**: ANIMATE FROM 0 TO TARGET (SUPPORTING DECIMALS) OVER ~2S USING `REQUESTANIMATIONFRAME`, TRIGGERED ONCE WHEN THE IMPACT SECTION ENTERS VIEW.
- **NAV / LINK FLIP-UP**: 500MS EASE TRANSFORM REVEALING THE GREEN-FILLED DUPLICATE LABEL.
- **MEGA MENU**: FADE + 8PX TRANSLATE IN ON TRIGGER HOVER, CONTENT SWAPPED BY DATA KEY, CLOSE ON WRAPPER MOUSE-LEAVE.
- **MARQUEE**: 30S LINEAR INFINITE LOOP, SEAMLESS.
- **CTA ARROW NUDGE, FAQ ICON ROTATE, IMAGE/LINK MICRO-HOVERS** AS DESCRIBED.

## RESPONSIVE BEHAVIOR

- DESKTOP: FULL CELLED NAV WITH MEGA MENU, TWO-COLUMN HERO, 4-UP GRIDS.
- TABLET: COLLAPSE 4-UP GRIDS TO 2-UP, STACK HERO COLUMNS, KEEP HAIRLINE FRAMES.
- MOBILE: HAMBURGER + FULL-SCREEN SLIDE-IN MENU, SINGLE-COLUMN STACKS, FLUID TYPE VIA `CLAMP()`, CTAS GO FULL-WIDTH. NO HORIZONTAL OVERFLOW.

## TECH & DELIVERY

- SINGLE SELF-CONTAINED STATIC BUILD (PLAIN HTML/CSS/JS IS ACCEPTABLE). VENDOR ALL ASSETS LOCALLY: SELF-HOST THE INTER TIGHT FONT FILES, DOWNLOAD ALL PORTRAIT/IMAGE ASSETS INTO A LOCAL `ASSETS/` FOLDER, AND DRAW ICONS AS INLINE SVG (NO ICON-FONT CDN). THE PROJECT MUST RUN FULLY OFFLINE.
